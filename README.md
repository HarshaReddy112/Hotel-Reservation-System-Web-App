# Hotel Reservation System

A Flask-based hotel reservation project with a frontend, backend, database schema, and supporting documentation.

## Project Structure

- backend/: Flask application, routes, models, and templates
- frontend/: HTML, CSS, JavaScript, and assets
- database/: SQL schema and seed scripts
- docs/: screenshots, architecture diagrams, and API docs
- .github/: issue templates, PR template, and CI workflow

## Getting Started

1. Create a Python virtual environment.
2. Install dependencies:
   - `pip install -r requirements.txt`
   - `pip install -r backend/requirements.txt`
3. Start the Flask app:
   - `python backend/app.py`

## Branches

- main: production-ready code
- develop: integration branch for ongoing development
